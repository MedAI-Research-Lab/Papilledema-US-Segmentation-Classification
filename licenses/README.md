# Upstream license texts

These files reproduce the upstream license texts identified in `provenance/third_party_dependencies.json`. They apply to their respective components, not automatically to every file in this repository. `THIRD_PARTY_NOTICES.md` records the distribution and attribution boundaries, including the separately acquired EMCAD source and the inherited U-Net helper lineage.

Original copyright statements and license text are retained without editorial changes. The EMCAD license is linked in the notices and remains with the user's own licensed source checkout; no EMCAD source is included here.
